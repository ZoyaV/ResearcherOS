Paper to PDF

koi-paper

Generate paper

Build a project paper draft from the queue and place its PDF in the repository.

What it does

Accepts a paper task, collects context from the project tree and reports, writes a draft, builds a PDF in the repository, and closes the task so the interface updates.

Why use it

Turn an accumulated research graph into a paper draft without manually collecting material from many directories.

When to use it

  • Generate paper was clicked
  • The paper queue contains a task
  • A Paper Inbox received a new-paper signal

How to invoke it

Ask the assistant to check the paper queue and process a task through PDF creation and closure.

Example request for the AI assistant in your editor:

Check the paper queue and process its task:
accept → collect context → draft → PDF → close.

Workflow diagram

Acceptance lets the interface show work in progress; closure after the PDF is built prevents the task from remaining pending.

flowchart LR
  A[Paper queue] --> B[Accept task]
  B --> C[Collect project context]
  C --> D[Draft paper]
  D --> E[Build PDF in project]
  E --> F[Close task]
