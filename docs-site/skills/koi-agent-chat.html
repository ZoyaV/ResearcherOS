Chat from the interface

koi-agent-chat

A question arrives from the Ask agent panel

Answer a panel question using findings first and reports when needed.

What it does

Retrieves a question from the UI queue. If it matches an existing finding, it answers quickly. Otherwise it reads the necessary reports and returns an answer to the chat panel. Operation can use a persistent Inbox chat, editor hooks, or an API key.

Why use it

Answer project questions from accumulated findings and reports while preserving research context.

When to use it

  • A new question appears in Ask agent
  • The queue has unanswered questions at session start
  • An answer must rely on stored findings

How to invoke it

Ask the assistant to check the interface-question queue and answer pending items. Configure an Inbox chat or hooks for faster operation.

Example request for the AI assistant in your editor:

Check the interface-question queue and answer all pending items using the ResearcherOS chat workflow.

Workflow diagram

Check the findings database first; read reports only when no suitable finding exists. Always return the answer to the queue for display.
