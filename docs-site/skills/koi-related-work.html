Related Work queue

koi-related-work

A Related Work task appears in the queue

Process a literature task from the UI queue and save the review on the Related Work page.

What it does

Accepts a literature task, retrieves its project and cluster context, writes the review, and saves the answer back to the Related Work page.

Why use it

Let literature analysis begin from UI-selected clusters and appear on the page without manual copying.

When to use it

  • A Related Work task entered the queue
  • A Literature Inbox received a signal
  • An accepted answer needs completion or resaving

How to invoke it

Ask the assistant to process the queue in order: accept → retrieve context → write review → save answer.

Example request for the AI assistant in your editor:

Check the Related Work queue and process its task:
accept → retrieve context → write the review → save the answer.

Workflow diagram

Every queue step is required: acceptance changes the UI state, and saving returns the text from the assistant to the page.

flowchart LR
  A[UI queue] --> B[Accept task]
  B --> C[Retrieve context]
  C --> D[Write review]
