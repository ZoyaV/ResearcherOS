Experiment report review

koi-report-review

Before a report is accepted or published

Check a report for evidence, reproducibility, and valid knowledge-base integration.

What it does

Reviews a working report against its specification, metrics, decision rule, artifacts, caveats, and proposed insights. It distinguishes measured facts from interpretation, checks reproducibility, and validates IDs and structured findings.

Why use it

Prevent unsupported verdicts, irreproducible results, and malformed insights from entering the knowledge base.

When to use it

  • A run report is ready for ingestion
  • A card is about to move to done
  • A working report needs conversion into a public report

How to invoke it

Ask the assistant to review a specific report and include the project plus report or card path.

Example request for the AI assistant in your editor:

Review the report for card <id> in project <project>:
check evidence, reproducibility, the verdict rule, caveats, and the integration block.

Workflow diagram

Check links and specification, execution evidence, metrics and verdict rule, caveats, and insights. Return corrections or approve ingestion and publication.

flowchart TD
  A[Open report and specification] --> B[Check links and reproducibility]
  B --> C[Verify metrics and artifacts]
  C --> D[Apply decision rule]
  D --> E[Review caveats]
  E --> F[Validate structured insights]
  F --> G{Ready?}
  G -->|no| H[Request corrections]
  G -->|yes| I[Ingest or publish]
