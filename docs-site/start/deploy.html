Use an existing ResearcherOS project

You or your team already have a hypothesis tree. Arrange the files correctly on disk and start the interface. Choose the case that applies to you. 

workspace/
├── ReseachOS/                      ← engine
├── tree/
│   └── <repo>/koi-structure/       ← koi/research branch
└── <repo>/                         ← code, any branch

The server enters tree and searches one level below for */koi-structure/project.md.

First setup on this machine

The koi/research branch already exists on the remote. Clone the engine and code repository, attach the research branch under tree/, and open the UI.

  1. Clone the engine and code repository side by side 
    git clone git@github.com:ZoyaV/ResearcherOS.git ReseachOS
git clone <your-code-repository-url>
# the two directories are siblings; directory names may vary
# workspace/ReseachOS/
# workspace/<repo>/
  2. Attach koi/research under tree/ 
    cd ReseachOS
./scripts/koi-serve.sh start
python -m koi.projects.install_cli install <repo>
# the code repository directory name on disk
python -m koi.projects.install_cli status

    This creates tree/<repo>/, a Git worktree on the koi/research branch containing koi-structure/.

  3. Open the interface 
    ./scripts/koi-serve.sh restart
# http://127.0.0.1:8080
# API: http://127.0.0.1:8010/docs

Migrate from the old layout

Research materials are local but not under tree/; they are in <repo>/koi-structure/ or <repo>/.koi-sync-worktree/. The code repository and engine are already side by side.

  1. Check that the CLI detects migration 
    cd ReseachOS
python -m koi.projects.install_cli status
# the target <repo> should have case: migrate_to_tree
  2. Move it under tree/ 
    python -m koi.projects.install_cli migrate <repo>
# equivalent to install; the CLI detects the case
./scripts/koi-serve.sh restart

    You can remove the old checkout from the code repository after verifying that tree/<repo>/koi-structure/project.md exists and the project appears in the UI. The paths remain in .gitignore on the code branch.

From then on, synchronize with the Sync button in the UI or python -m koi.projects.sync_cli pull|push --project-id <id>. If no hypothesis tree exists yet, follow Connect my code for the first time and prompt the agent.
