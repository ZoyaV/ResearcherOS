Start from scratch — no code yet

Create the hypothesis map first. Experiment code can be added later in <repo>/projectcode/.

With one command

  1. Clone and start ResearcherOS 
    git clone  ReseachOS
cd ReseachOS
./scripts/koi-serve.sh start
  2. Create an empty project 
    python -m koi.projects.install_cli install my_idea \
  --create --title "My research problem"
./scripts/koi-serve.sh restart
# http://127.0.0.1:8080

    The following appears on disk:

    tree/my_idea/koi-structure/   ← project.md, research.json
my_idea/projectcode/          ← code goes here

In the interface

  1. Open http://127.0.0.1:8080 and click + New project in the project list. Enter a title, description, short Latin-character slug, and program.
  2. A problem appears on the map; add causes, hypotheses, and methods with +.

With the assistant in your editor

Prompt:

Create a new ResearcherOS project from scratch.

1. Ask me about the problem, domain, and realistic experiments.
2. Propose a tree: problem → causes → hypotheses → methods.
3. Create it with
   python -m koi.projects.install_cli install <slug> --create
   (tree/<slug>/koi-structure + <slug>/projectcode).
4. Write clearly. Do not commit unless I explicitly ask.
