Connect my code for the first time

The experiment code already exists, but there is no research map yet. The AI assistant builds a hypothesis tree and places the materials in tree/<repo>/koi-structure/ (branch koi/research).

  1. Place ResearcherOS beside the code 
    git clone  ReseachOS
# your code repository is already beside it, for example:
# workspace/ReseachOS/
# workspace/my_experiment/
cd ReseachOS
./scripts/koi-serve.sh start
  2. Ask the agent to create the tree

    In Cursor, Claude Code, or another agentic IDE, open the ReseachOS repository and paste this prompt after substituting your repository path: 

    Connect ../my_experiment to ResearcherOS.

Follow agents/skills/koi-project-onboard/SKILL.md through to completion:
Socratic dialogue (problem → program → causes/hypotheses → methods),
prose review, write to tree/my_experiment/koi-structure/,
then run python -m koi.projects.install_cli install my_experiment
(koi/research branch + worktree under tree/).

Do not change git config or commit secrets (.env).

    The agent asks several academic questions, proposes node wording, and writes files only after you say “write.” Workflow details: koi-project-onboard.

  3. What appears in the project

    The disk layout will look like this:

    workspace/
├── ReseachOS/                         ← engine
├── tree/
│   └── my_experiment/
│       └── koi-structure/
│           ├── project.md             ← hypothesis tree + kanban
│           ├── onboard-brief.md       ← specification anchor from the dialogue
│           ├── research.json
│           └── reports/
└── my_experiment/                     ← your code, any branch
    └── …

    In the interface (http://127.0.0.1:8080; if needed, ./scripts/koi-serve.sh restart):

    • a sidebar project using your problem statement;
    • problem → cause → hypothesis → method nodes on the map;
    • empty or seeded kanban cards under methods for the first experiments.

If your team already has a koi/research branch and the tree does not need to be rebuilt, see Use an existing ResearcherOS project for first setup on a machine or layout migration.
