About

What it is. ResearcherOS supports research from hypotheses to reports and accumulated knowledge. Everything is stored in ordinary text files and travels with the project repository.

Who it is for. Researchers and small teams, including machine-learning teams, who already have experiment code or will soon create it and need a shared view of what is being tested, what has been learned, and where to go next.

Why. Important work should not disappear into chats and drafts. Specifications, runs, and findings remain in the repository, visible to both people and the AI assistant in the code editor through one interface.
