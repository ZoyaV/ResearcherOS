Research step by step

ResearchOS

A web interface for research projects. All data is stored in text files in the repository, without a separate database. The experiment cycle is: problem → hypotheses → kanban → report → knowledge base. Literature review is handled separately on its own page.

Scroll down—the steps mirror the stages in the interface.

Step 1

Problem

The root of the tree states the research problem. From it, add hypotheses about why the problem occurs and how it can be tested or remediated.

Problem

Step 2

Hypothesis tree

The chain is: cause → evidence or remediation → test method. Each node has an open, supported, or refuted status. The tree appears on the hypothesis map in the workspace.

Cause Evidence Remediation Method

Step 3

Experiment kanban

Each method has its own board: backlog, in progress, and done. One card represents one experiment. Before launch, define the numerical conditions under which the hypothesis is considered supported or refuted. 

Example rule:
supported — if the metric exceeds the threshold
refuted — if the condition is not met
otherwise the hypothesis remains open

Step 4

Report and verdict

Each experiment produces a report linked to its card, with an explicit verdict and up to three brief findings. After format validation, insights enter the project knowledge base. This knowledge comes from your experiments, not from published papers.

Uploading the same report again changes nothing; editing it updates the card findings.

Step 5 · laboratory knowledge

Knowledge base

Accumulated findings from your laboratory's experiments: hypothesis verdicts and insights from kanban-card reports. Each item links to its source report. The team's review notes are kept separately and curated manually.

This is not a literature review; external papers and their clusters appear in steps 7–8.

Step 6

Agent in the editor

The agent in the development environment helps run experiments and write reports, answers questions from the Ask Agent panel, and formulates findings for completed cards.

Ask Agent Synchronization

Step 7 · publication review

Literature review — search

This is separate from the experiment knowledge base. On its own page, search the team's library by research question, ranked by title and abstract, and select papers for review.

Team library Review set

Step 8 · publication review

Literature review — clusters

The agent summarizes selected papers and groups them into clusters representing different lines of published answers to your question. This maps external work; verdicts on your own hypotheses remain in the experiment knowledge base.

Paper summaries Paper clusters
